# VoxCPM2 reference voices

VoxCPM2 picks a new speaker for every sentence unless it is given a voice to
clone, so each language it speaks gets one fixed reference clip here.
`scripts/prepare-voices.sh` copies them to `/workspace/voices/voxcpm/` (never over a
file already there); `server/voxcpm_service.py` clones `<lang>.wav`.

All were generated by VoxCPM2 itself (48 kHz mono): they are synthetic
speakers, not recordings of real people. To change a voice, replace the file
here and delete the copy on the volume so the next start copies it.

**How the seven commercial voices were chosen** (2026-09-29, A100,
`tools/voice_refs.py`): per language, four candidates, A a designed "calm,
clear adult woman", B a designed "calm, clear adult man", C and D random
speakers, each saying a short welcome. Each was cloned on three test sentences.
A candidate counted as stable when every clone's median pitch stayed within 25%
of the reference's and on the same side of 165 Hz (the Lao lesson: a man
turning into a woman mid-phrase); among the stable ones, the lowest Whisper
large-v3 character error rate won (ties: the first). Scores for every
candidate and clone: [`eval/2026-09-commercial-refs/meta.json`](../../eval/2026-09-commercial-refs/meta.json).

**To listen to before these ship (owner):** all seven. A number can't hear
naturalness or an odd accent. Worth a particular ear: `ar.wav` (very low
pitch; C is the alternative), `sw.wav` (its clones drift from 154 to 101 Hz,
inside the threshold but the widest spread), and `vi.wav` (110-147 Hz).

Arabic, Indonesian and Russian were re-picked by the owner after listening (2026-09-29): a second round of four candidates per language (same method, `tools/voice_refs.py gen`) plus the first round's pick, each reading the same three sentences. The first Arabic pick changed pitch mid-phrase (~80 to 163 Hz). Korean, Swahili, Turkish and Vietnamese kept their first-round picks.
